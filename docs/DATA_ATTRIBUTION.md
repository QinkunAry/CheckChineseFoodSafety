- License: 政府資料開放授權條款-第1版
- License text: <https://data.gov.tw/license>

> 資料提供：衛生福利部食品藥物管理署，2026，《不符合食品資訊資料集》（資料提供者未標示獨立版本號）；本專案提供標準化衍生資料。
